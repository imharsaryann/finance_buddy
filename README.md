# Finance Buddy 💰

Finance Buddy is a comprehensive personal finance dashboard that helps you track your incomes, expenses, bank accounts, credit cards, borrowers, and savings schemes (Samiti) all in one beautiful, glassmorphic UI.

## 🚀 Features
- **Dashboard Overview**: Get a quick glance at your total balance, monthly income, and expenses.
- **Transactions**: Track daily expenses and incomes sorted by categories.
- **Banks & Cards**: Manage multiple bank accounts and track credit card limits, outstanding balances, and due dates.
- **Borrowers Tracker**: Keep track of money lent to others and their repayments.
- **Samiti (Chit Funds)**: Manage group saving schemes and track monthly payments easily.
- **Data Visualization**: Beautiful charts (Bar, Line, Doughnut) to analyze your financial health.

## 🛠️ Tech Stack & Tools Used
This project is built using modern web technologies:

- **Frontend Framework**: React (v19.2) powered by Vite for blazing fast performance.
- **Styling**: Vanilla CSS with a modern Glassmorphism design aesthetic (blur effects, transparency).
- **Icons**: [Lucide React](https://lucide.dev/) for crisp, consistent scalable vector icons.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for smooth layout transitions and micro-interactions.
- **Charts**: [Chart.js](https://www.chartjs.org/) & `react-chartjs-2` for rich, interactive data visualizations.
- **Counters**: `react-countup` for dynamic number increment animations.
- **Backend / Database**: [Supabase](https://supabase.com/) (PostgreSQL & Authentication) as the Backend-as-a-Service.
- **Utilities**: Puppeteer (for automated tasks or PDF generation).

## 🏃‍♂️ Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
